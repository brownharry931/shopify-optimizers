**Subtitle (≤ 62 characters):**

**Introduction (≤ 100 characters):**
Run Google Lighthouse audits on your store and switch on speed settings without editing theme code.

**Details:**
SpeedBoost shows how fast your storefront loads using Google PageSpeed
Insights — the same Lighthouse engine as pagespeed.web.dev — and gives you
switches for common speed improvements that run through a theme app embed.
Your theme code is not edited by the speed settings, and turning one off
undoes it immediately.

- Speed audits for any store page on mobile and desktop, with the four
  Lighthouse scores, Core Web Vitals, screenshots and real-visitor data from
  the Chrome UX Report when Google has it.
- Image report comparing the bytes downloaded today with a correctly sized
  version from Shopify's image CDN.
- Speed settings: delay third-party app and tracking scripts until the
  visitor interacts, lazy-load video embeds, preload product images and
  theme fonts, prefetch pages visitors are about to open, page-stability
  styles and a loading bar.
- Theme optimizer for unpublished themes: minify CSS/JS and add lazy loading
  to images, with rollback.
- History and trends of every audit.

Results vary by theme, apps and content. Lighthouse scores change slightly
between runs.

**Feature bullets (up to 3, ≤ 80 characters each):**
1. Lighthouse audits with Core Web Vitals for any page, mobile and desktop
2. Reversible speed settings through a theme app embed — no code edits
3. Score history to compare before and after each change
